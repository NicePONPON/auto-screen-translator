## Auto Screen Translator for Windows

Auto-built from the latest source on main.

### How to install
1. Download AutoScreenTranslator-Windows.zip below
2. Right-click the zip, Properties, check Unblock, click OK
3. Extract the zip to any folder, e.g. C:\AutoScreenTranslator\
4. Double-click AutoScreenTranslator.bat
5. On first launch, enter your free Gemini API key when prompted
   Get one free at aistudio.google.com/apikey (no billing required)

### How to use
- Capture: drag to select any screen region
- Translation appears as a card in the floating panel
- Click any card to copy the translation to clipboard
- Press Ctrl+V in your form field to paste

### First launch
Enter your Gemini API key once. Free tier: 1500 requests/day, no credit card needed.
The S button in the toolbar opens the key settings at any time.
